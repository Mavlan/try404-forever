# Try404 Guide

魔兽世界：永恒的中文社区插件，提供装备、副本、任务、专业技能和职业小工具等资料。

TRY404 is an independently maintained community fork of [OneForAll - Forever](https://github.com/smoergi/OneForAll_Forever) by Smoergi and contributors, with Simplified and Traditional Chinese support. It is not an official OneForAll release.

## 安装和使用

从 [CurseForge](https://www.curseforge.com/wow/addons/try404) 或 [TRY404 官网](https://try404.com/wow4ever/) 下载，将 `Try404Forever` 放进游戏的 `Interface/AddOns` 文件夹。游戏内输入 `/try404` 打开手册。
